MEDIUM potential FILTER over entire table 'Sales' used as CALCULATE filter in '_Measures'[High Value Revenue]DAX003-97330947

Source

ContosoRetail.SemanticModel/definition/tables/_Measures.tmdl:14 · ContosoRetail/measure/_Measures/High Value Revenue/filter-1

Evidence

  • CALCULATE( ..., FILTER(Sales, ...) ) at expression line 4
  • 'Sales' structural role: fact

Explanation

A table filter iterates every row of the (expanded) table and keeps all its columns as filter.

Impact

Often slower than a column predicate and may filter related tables more than intended.

Recommendation

Use column predicates (e.g., 'T'[Col] > x) or FILTER(VALUES('T'[Col]), ...); add KEEPFILTERS if the intent is to intersect with existing filters.

How to verify

Compare query duration (Performance Analyzer / DAX query view) before and after the change.
